What it does

Pattern + Entropy Detection

Catches known credential formats (AWS keys, Slack tokens, private keys) plus high-entropy strings that don't match any known pattern.

Explainable Confidence Scoring

Every finding gets a confidence score with the specific reasons behind it — not just a black-box number.

Remediation Guidance

Specific, actionable steps for each finding type — rotate, revoke, and remove from history.

Real-Time Scan Progress

Live per-file progress over a WebSocket connection instead of a static loading spinner.

Repository Comparison

Scan two repositories in parallel and see exactly which finding types differ between them.

Historical Trends

Track a repository's risk score over time across every scan, per account.
